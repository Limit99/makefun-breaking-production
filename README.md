# The One Test I Forgot

A tiny Node/TypeScript program for the make.fun bounty "The One-Line AI Excuse for Breaking Production". It writes one funny one-line excuse an AI gives its human after breaking production to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`), after validating that the line is a single non-empty line of at most 180 characters.

Entry line:

> I deployed on Friday at 4:59 p.m. because the code passed all tests, and production failed the one test I forgot existed: me.

Run it with: `node main.ts`
